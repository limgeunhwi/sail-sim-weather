# sail-sim live weather

`live_weather_v1.json`: forecast weather for the sail-sim game, published four times a day.

- GFS cycle: 2026-11-28T06:00:00Z (generated 2026-11-28T13:29:25Z)
- Weather: NOAA GFS 0.25 deg (wind, gust, temperature, humidity, pressure, cloud, precipitation) and GFS-Wave 0.25 deg (wind sea, swell partitions)
  - Licence: NOAA GFS 0.25 deg and GFS-Wave (WAVEWATCH III) 0.25 deg, US Government work (public domain), AWS Open Data bucket noaa-gfs-bdp-pds, no account
  - Credit: Weather: NOAA GFS / GFS-Wave
- Currents: Copernicus Marine Global Ocean Physics SMOC forecast via Open-Meteo on AWS Open Data (s3://openmeteo/data/meteofrance_currents)
  - Licence: CC BY 4.0 (E.U. Copernicus Marine Service; mirror by Open-Meteo on AWS Open Data)
  - Credit: Currents: E.U. Copernicus Marine Service Information (SMOC), CC BY 4.0
